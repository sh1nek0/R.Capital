# Capital OS Navigator v0.1 Product Scope

## Product Goal

Capital OS Navigator is a diagnostic SaaS that helps a founder understand:

- current startup stage;
- suitable financing routes;
- routes that are premature;
- documents and metrics to prepare;
- the next practical steps for 30 days.

## Core User Flow

```text
Founder opens landing page
-> completes diagnostic questionnaire
-> system creates startup profile
-> system calculates Funding Readiness Score
-> system recommends financing route
-> founder receives web report
-> founder requests deeper expert review
-> Capital OS team processes the request in admin console
```

## MVP Boundary

The MVP is not an investment platform. It must not include:

- investor account;
- accepting investor funds;
- equity marketplace;
- investment offers;
- deal execution;
- promised returns;
- automated applications to funds;
- legally significant data room.

## MVP Success Signals

- founders complete the diagnostic;
- founders perceive the roadmap as useful;
- founders request expert review;
- repeated pains and routes become visible;
- some users are ready to pay for deeper preparation.
